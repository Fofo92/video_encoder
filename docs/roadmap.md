# Roadmap

## Distribution locale de CCExtractor

Prochaine étape :

- construire une version locale et versionnée de CCExtractor avec OCR ;
- fournir le modèle linguistique français validé ;
- documenter les dépendances et les options de compilation ;
- enregistrer les versions et les empreintes des artefacts ;
- vérifier l’installation avec un test OCR minimal ;
- exécuter le projet d’acceptation multi-source ;
- comparer son résultat avec celui de l’image conteneurisée de référence.

L’image conteneurisée actuelle est conservée comme référence et comme option de
déploiement futur. Elle ne constitue pas une dépendance obligatoire du fonctionnement local.
