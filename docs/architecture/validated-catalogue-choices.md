# Choix de catalogue et nouvelles destinations

Les épisodes dont la série est documentaire sont proposés dans `/videos/Documentaires`.
Les genres et pays propres à la série sont transmis par vidb, avec repli sur ceux
hérités par l'épisode pour les anciennes réponses. Une destination manuelle
explicite reste conservée ; aucun dossier n'est créé par la proposition.

Pour les nouveaux noms de fichiers et dossiers, la présence de France dans les
pays de production (coproductions comprises) entraîne l'emploi du titre français
seul. Sinon, les titres français et original restent présents, même identiques.
Les données éditoriales originales de vidb restent conservées.

Une version VF, VM ou VMST validée dans vidb prime sur la déduction de langue
originale : VF conserve le français et les sous-titres forcés ; VM conserve les
pistes française et originale sans sous-titres complets ; VMST utilise le parcours
multilingue avec sous-titres français. VM ne perd pas sa VO en l'absence de texte
extrait. Une version indéterminée utilise les preuves externes ou la question
manuelle existante. La présence des pistes reste soumise au contrôle audio.

Les décisions de pistes déjà enregistrées avec une portée valide sont réutilisées.
Aucune tâche en attente, aucun chemin de projet ni fichier existant n'est réécrit
par l'installation du correctif. Aucun traitement de migration n'est lancé.
